# Incident Response

- Family: `incident`
- Approval required: yes
- Tool connections: `observability`, `repo`, `statuspage`
- Expected artifacts: `incident-timeline`, `impact-summary`, `resolution-summary`
- Failure modes: `tool-unavailable`, `approval-rejected`, `mitigation-failed`

Steps:

1. Gather signals
2. Draft incident pack
3. Request mitigation approval
4. Execute mitigation
5. Record resolution
